# Hospital Service Comparison

A healthcare web application designed to help patients compare hospitals and diagnostic services.

## Features
- Search nearby hospitals
- Compare diagnostic test prices
- View hospital ratings and locations
- Request appointments
- Hospital administrator dashboard
- Machine learning-based comparison

## Technology Stack
- Python
- Streamlit
- FastAPI
- PostgreSQL
- Machine Learning
